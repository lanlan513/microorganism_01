# 活体培养皿 · Incubator

把馆内任意标本接种进同一枚培养皿，观察它们按真实生态规律**分裂、争夺碳源、被抗菌素压制、完成优势种更替**。

## 权威边界（最重要的设计）

- **模拟只在服务端推进**。随机源、时间步、摄食/感染/扩散全部在 Node 中执行
  （`shared/sim/engine.ts`，依赖 `node:crypto`），浏览器包里不含任何推进代码。
- **前端只画与播**。浏览器通过 `/api/petri/runs/:id/frames` 拉取权威二进制帧
  （`shared/sim/codec.ts` 的 13B/细胞紧凑格式），逐帧播放；相邻帧之间只做纯视觉插值，
  任何插值结果不回灌数据。改前端代码无法改变任何结果。

## 可复现性

同一份接种清单 + 同一个种子，在任何时间、任何机器重放，都走出**逐格完全相同**的种群数量序列：

- 单一确定性随机流（Mulberry32），细胞按 id 升序迭代，网格扩散固定次序、双缓冲；
- 不读墙钟，计数一律定点整数落盘；
- 标本性状由 `microbeId` 稳定哈希派生，故不同接种必然产生不同指纹。

**生态指纹（Eco Fingerprint）** 包含：

- 逐格计数规范序列的 SHA-256（`transcriptHash`）与哈希链末端（`chainTip`）；
- 第 50/100/200/400/600 及末代检查点的细胞数与四类占比（千分位）；
- 最终优势种、灭绝顺序、结局（稳定 / 全部灭绝 / 达 900 代上限）。

指纹面板上的"服务器复核"会让后端**从头重放**整段模拟并逐格比对，
同时独立重算科考日志哈希链（以 `petri-genesis/<runId>` 锚定），档案被篡改即可被抓出。

## 科考留痕

每次运行在 `data/petri/` 下落盘（已在 .gitignore）：

- `manifest.json`：请求、指纹、逐格计数、逐步事件、帧偏移索引；
- `frames.bin`：逐帧权威二进制（12B 头 + 13B/细胞）；
- `verify.json`：最近一次复核结论。

同样的种子与接种清单生成同一个 `runId`，请求幂等。

## 前端渲染（纯 Canvas，无图形库）

- 按 `devicePixelRatio` 建位图，高分屏不发虚；
- 手写四类形态：杆体+周身摆动鞭毛（细菌）、芽生菌丝球（真菌）、棱角 S 层（古菌）、
  蝌蚪形头-尾鞘-尾丝（病毒）；
- 菌落边缘：40×40 占用网格 + marching squares；
- 悬停出现圆形 4× 显微镜镜头（裁剪后按视野重绘、十字标尺、50 μm 标尺、单细胞状态读数）；
- 播放/暂停、1–100× 变速、进度拖动（基准 12 代/秒）；
- 细胞绘制带 6ms 时间预算分批，超预算让出主线程。基准测试（`scripts/render-bench.ts`）
  1400 细胞约 1.3ms/帧。

## 生态机制（每固定时间步）

运动 → 病毒吸附/感染推进与裂解 → Monod 摄食（细菌嗜富营养、古菌寡营养低 Ks）
→ 维持消耗/饥饿/抗生素损伤（耐受性按种，铜绿假单胞菌、芽孢杆菌更高）
→ 产黄青霉分泌青霉素并扩散衰减 → 二分裂（拥挤限制）→ 尸体碳回收 → 场扩散。

标定可见的真实动态：纯细菌"暴发—碳枯竭—灭绝"；青霉把无耐药菌长期压制在低密度；
T4 与大肠杆菌走出捕食振荡后同归于尽；枯竭后寡营养古菌接管成优势种。

## 常用命令

```bash
npm run dev          # 前端 5173 + API 3001（vite 代理 /api）
npx tsx scripts/sim-tune.ts     # 确定性回归与场景序列
npx tsx scripts/codec-test.ts   # 帧编解码往返测试
npx tsx scripts/render-bench.ts # 渲染性能基准
```

页面入口：导航栏"活体培养皿"，或 `/incubator`。
